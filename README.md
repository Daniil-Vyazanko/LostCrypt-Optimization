Оптимизация игрового проекта Lost Crypt (Unity)
Курсовая работа по оптимизации игрового проекта.

Направления оптимизации:
1. **CPU и скрипты:** Устранены аллокации памяти (GC Alloc) в Update-циклах за счет кэширования векторов.
2. **Рендеринг:** Отключены динамические тени у второстепенных источников 2D-света, снижено разрешение рендер-текстур, отключены тяжелые эффекты постобработки.
3. **Память:** Настроены Sprite Atlases и оптимизированы настройки сжатия текстур.

Результаты (До / После):
1. GC Alloc в кадре:** 2.3 MB -> 0 B
2. Draw Calls:** 195 -> 180
3. Render Textures Changes:** 24 -> 8
4. Потребление памяти (Total Committed):** 0.76 GB -> 0.67 GB

Теги в репозитории:
1. `before-optimization` — исходное состояние проекта.
2. `after-optimization` — проект после внедрения оптимизаций.
